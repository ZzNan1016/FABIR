# FABIR

Official implementation of FABIR, a multimodal framework for cancer survival prediction.

**Repository status:** The source code and research data are not included in this initial repository setup.

## Planned structure

- `configs/` — experiment configurations
- `fabir/` — model and training implementation
- `scripts/` — training and evaluation utilities
- `metadata/` — permitted metadata required by the pipeline
- `splits/` — cross-validation split definitions
- `tests/` — basic tests
- `paper_weights/` — optional released model checkpoints

## Data and pretrained models

Patient-level data, whole-slide images, extracted image features, and pretrained CONCH weights are not distributed here. Obtain and use these resources only from their authorized sources and comply with their terms.

## Citation

Please cite the FABIR paper when using this work. Full citation details will be added after publication.
